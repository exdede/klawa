# Third-party data

- `Keyboard/words.txt`: built by `scripts/gen-words.py` from
  [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles 2018 word counts),
  licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The trimmed list is shared under the same license.
- `Keyboard/emoji.txt`, `Keyboard/emoji-keywords.txt`: built by `scripts/gen-emoji.py` from Unicode
  `emoji-test.txt` and CLDR annotations, © Unicode, Inc., [Unicode License v3](https://www.unicode.org/license.txt).
- `Keyboard/next.txt`: word-pair counts built by `scripts/gen-next.py` from the start of the OpenSubtitles v2018
  monolingual corpus on [OPUS](https://opus.nlpl.eu/OpenSubtitles/corpus/version/OpenSubtitles) (opensubtitles.org;
  P. Lison and J. Tiedemann, 2016, "OpenSubtitles2016: Extracting Large Parallel Corpora from Movie and TV Subtitles").
- `Keyboard/emoji-tones.txt`: from Unicode `emoji-test.txt`, as above.
